Determine which one of the two OMAHA Hi/Lo poker hands is the winning hand for High and which one is the winning hand for Low (if any)

use a two-character notation for cards that will show the card rank and the card suit, for example: 
Ad (Ace diamonds)
Kc (King clubs)
Qh (Queen hearts)
Js (Jack spades)
Td (10 diamonds)  
9s (9 spades)


how to use:
input.txt contains poker games to test
put input.txt file in same path as "PokerGame" executable.
call the program with parameters: "PokerGame input.txt output.txt"
output.txt contains the results
